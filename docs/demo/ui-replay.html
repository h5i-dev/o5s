o5s · octopus

Verified version control
for agent swarms.

Every change is an immutable patch. Agents propose against what they saw; non-conflicting patches merge in any order with the same result. The core is proved in Lean 4 against the Rust that runs.

// eight arms, one channel.

repositories ↩
01 · no rebase

Patches, not pushes.

Disjoint patches commute. Different lines of one file merge; nobody loses a race.

02 · conflicts

Conflicts are data.

Overlapping edits stay side by side until a reviewed resolution patch is admitted.

03 · review

Gated admission.

A patch enters a channel only with an independent approval and a passing check.

04 · proofs

Verified core.

Every registry decision is extracted Rust, proved in Lean: invariant, gate, isolation.
